## 1. Цель

Лёгкий видеоплеер для Windows по мотивам BSPlayer, с упрощённым набором функций:
раздельные окна видео / панели управления / плейлиста, безрамочные окна, удобное
перетаскивание и изменение размера, автоматический плейлист из папки, выбор аудиодорожек
и субтитров, удобные горячие клавиши.

Название программы: **Kadr** (от слова «кадр»). Предложено Claude по просьбе пользователя;
пользователь может переименовать позже.
Имя проекта и exe — `Kadr` / `Kadr.exe`, папка настроек — `%APPDATA%\Kadr`.

## 2. Платформа, стек, окружение

- **ОС:** только Windows (10/11), x64. **[утверждено]**
- **Разработка:** на домашнем компьютере пользователя, ограничений на установку и загрузки нет. **[утверждено]**
- **Язык / UI:** C# + WPF (.NET). **[утверждено]** Версия .NET — актуальная LTS
  (проверить, что установлено вместе с Visual Studio, `dotnet --list-sdks`).
- **IDE:** не обязательна. Сборка и запуск — из командной строки (`dotnet build`), это делает Claude.
  На компьютере установлены .NET SDK 6, 8 и **10** (проект на .NET 10 LTS); Visual Studio и VS Code
  **не установлены** и для работы не нужны. Если пользователь захочет смотреть код сам —
  можно поставить Visual Studio Community (набор «Разработка классических приложений .NET»)
  и открыть `Kadr.slnx`. **[утверждено]**
- **Движок воспроизведения:** **libmpv** (`libmpv-2.dll`). **[утверждено]**
  - Сборка: https://github.com/shinchiro/mpv-winbuild-cmake/releases — архив `mpv-dev-x86_64-…7z`
    (не `v3`). Нужен один файл `libmpv-2.dll`, кладётся рядом с exe
    (в проекте — копировать в выходную папку при сборке).
  - libmpv сам содержит FFmpeg: системные кодеки (K-Lite и т. п.) **не нужны и не используются**.
- **Обёртка libmpv:** предпочтительно своя тонкая P/Invoke-обёртка над client API
  (`mpv_create`, `mpv_initialize`, `mpv_set_option_string`, `mpv_command`, `mpv_get_property`,
  `mpv_observe_property`, `mpv_wait_event` / `mpv_set_wakeup_callback`, `mpv_terminate_destroy`).
  NuGet доступен, но сторонние пакеты — только если реально упрощают дело. **[по умолчанию]**
- **Git for Windows** установлен (нужен для Claude Code).
- Референс с открытым кодом: проект **mpv.net** (C# + WPF + libmpv) — можно подсматривать решения.

### 2.1. Структура папки проекта (`E:\KADR`)
- `CLAUDE.md` — этот файл. Сессию Claude Code открывать **в папке `E:\KADR`**, иначе файл не подхватится.
- `Kadr.slnx` — решение; `Kadr\` — сам проект (`Kadr.csproj`).

- Отладка mpv: переменная окружения `KADR_MPV_LOG=<путь к файлу>` включает подробный журнал mpv.
  Быстрая проверка без видеофайла: `Kadr.exe "av://lavfi:testsrc=size=1280x720:rate=25"`.
- Git: репозиторий в `E:\KADR`, ветка `main`; коммитить после каждого проверенного этапа.

## 3. Окна

Три независимых окна на один экземпляр плеера: **видео**, **панель управления**, **плейлист**. **[утверждено]**

Общие правила:
- Все три окна **без рамки** (`WindowStyle=None`). **[утверждено]**
- Все три окна **свободно перетаскиваются мышью**, в том числе между мониторами. **[утверждено]**
- Корректная работа на мониторах с разным масштабом: Per-Monitor DPI Aware v2 (app.manifest). **[по умолчанию]**
- Окна одного экземпляра ведут себя как группа: сворачиваются/восстанавливаются вместе,
  F10 закрывает все три. **[по умолчанию]**
- Кнопка на панели задач — одна на экземпляр (окна панели и плейлиста — owned). **[по умолчанию]**
- Если сохранённая позиция окна оказалась за пределами текущих мониторов
  (монитор отключили) — вернуть окно на основной монитор. **[по умолчанию]**

### 3.1. Окно видео
- Только картинка, никаких элементов управления. **[утверждено]**
- **Колёсико мыши (поворот) над окном видео меняет размер окна** с сохранением пропорций видео —
  это основной способ менять размер, пользователь подтвердил дважды. **[утверждено]**
  Колесо от себя — больше, на себя — меньше; шаг ~10% от текущего размера, масштаб относительно
  центра окна, минимум ~320 px по ширине, максимум — рабочая область монитора. **[по умолчанию]**
  Пункт меню «Размер окна» (раздел 13.1) — дополнение для точных размеров, не замена колеса.
- **Перетаскивание за любую точку картинки.** **[утверждено]**
- **Клик без движения мыши — пауза/воспроизведение (в оконном режиме); клик с движением — перетаскивание окна.** **[утверждено]**
  Порог движения — несколько пикселей (системный `SystemParameters.MinimumHorizontalDragDistance`).
- **Двойной клик — полноэкранный режим** (на том мониторе, где окно). **[утверждено]**
  Важно: одиночный клик (пауза) не должен срабатывать при двойном. Вариант: откладывать
  действие одиночного клика на время двойного клика (`GetDoubleClickTime`) и отменять, если пришёл второй клик.
- **Полноэкранный режим** **[утверждено]**:
  - при входе панель управления и плейлист **прячутся**;
  - **одиночный клик левой кнопкой по видео показывает/скрывает панель управления**
    (в полноэкранном режиме клик НЕ ставит паузу; пауза — пробелом или кнопкой на панели);
  - показанная панель находится поверх полноэкранного видео (topmost); её можно перетащить,
    в том числе на соседний монитор — пользователь так и планирует делать, если она мешает;
  - плейлист в полноэкранном режиме остаётся скрытым, пока его не вызовут (клавиша `L` / меню);
  - при выходе из полноэкранного режима панель и плейлист возвращаются на места, где были
    до входа в полный экран. **[по умолчанию]**
  - В оконном режиме правило прежнее: одиночный клик = пауза.
- Правая кнопка — контекстное меню (состав утверждён, см. раздел 13.1).
- Перетаскивание файла на окно видео — открыть файл (плейлист заменяется содержимым его папки).

### 3.2. Окно панели управления
- Перетаскивается за любое свободное место (не кнопки и не полосы). **[утверждено]**
- Состав и раскладка — см. раздел 4 (дизайн утверждён).

### 3.3. Окно плейлиста
- Отдельное, третье окно. **[утверждено]**
- Перетаскивается за свободное место (заголовок, пустые области). **[утверждено]**
- Кнопка закрытия (скрывает окно, не закрывает программу). Показ снова — кнопка «Плейлист» на панели.

## 6. Плейлист — правила

### 6.1. Автоматическая загрузка папки [утверждено]
При открытии одного файла (двойной клик в проводнике / «Открыть с помощью» / аргумент
командной строки / перетаскивание на окно видео):
1. Плеер читает **всю папку** этого файла и берёт **все видеофайлы**.
2. Сортирует **по алфавиту, «естественной» сортировкой**: «Серия 2» раньше «Серия 10»
   (как в проводнике Windows — `StrCmpLogicalW` из shlwapi), без учёта регистра.
3. Запускает **именно открытый файл**, на его месте в списке.
4. Файлы субтитров в плейлист **не попадают** (они подхватываются к своему видео, см. раздел 7).

Расширения видео (без учёта регистра) **[по умолчанию]**:
`mkv, mp4, m4v, avi, mov, wmv, webm, ts, m2ts, mts, mpg, mpeg, flv, 3gp, ogv, vob, divx, rmvb`.

### 6.2. Ручное добавление [утверждено]
- Через контекстное меню окна плейлиста: «Добавить файлы…», «Добавить папку…»,
  «Удалить выбранный», «Очистить», «Сортировать по имени».
- Перетаскивание файлов и папок **в окно плейлиста**.
- Добавленные вручную файлы **встают в конец списка** (ручной порядок не ломается).
- Пункт **«Сортировать по имени»** упорядочивает весь список по алфавиту (естественная сортировка).
- **«Добавить папку» берёт видео из папки и из ВСЕХ её подпапок** (рекурсивно). **[утверждено]**
  То же при перетаскивании папки в окно плейлиста.
  Порядок внутри добавленной папки — естественная сортировка по относительному пути
  (сначала по подпапкам, затем по именам файлов), чтобы «Сезон 1» шёл раньше «Сезон 2»,
  а «Сезон 2» раньше «Сезон 10». **[по умолчанию]**
  Скрытые и системные папки пропускать; ошибки доступа к отдельной подпапке не должны
  прерывать добавление остальных. **[по умолчанию]**
- Автозагрузка при открытии одного файла (6.1) берёт **только его папку**, без подпапок. **[утверждено]**
- Клавиша Delete в окне плейлиста удаляет выбранный пункт из списка (не с диска!). **[по умолчанию]**

### 6.3. Открытие нового файла
- Новый файл из проводника запускает **новый экземпляр** плеера (см. раздел 10).
- Перетаскивание файла **на окно видео** уже открытого плеера — **заменяет** плейлист содержимым
  папки этого файла. Перетаскивание **в окно плейлиста** — добавляет в конец.

## 7. Субтитры и аудиодорожки [утверждено]

- Выбор **аудиодорожки** из имеющихся в файле: меню «Аудио» + клавиша `A` (по кругу).
- Выбор **встроенных субтитров** и их отключение: меню «Субтитры» + клавиши `S` (вкл/выкл),
  Shift+S (следующая дорожка субтитров).
- **Внешние субтитры** `.srt`, `.ass`, `.ssa` (и прочие, что понимает mpv) **из той же папки**
  подхватываются автоматически (`sub-auto=fuzzy`).
- Кириллические `.srt` часто в кодировке Windows-1251 — проверить, что отображаются
  без «кракозябр» (`sub-codepage=auto`); протестировать на реальном файле пользователя.
- В меню показывать название дорожки, язык и кодек/каналы, если есть
  (например, «Русский — AC3 5.1»). Данные — из свойства mpv `track-list`.
- **Сдвиг субтитров** по времени: `Z` / `X` — минус/плюс 0.1 с. **[по умолчанию]**
- **Сдвиг аудио** относительно картинки: Shift+Z / Shift+X — минус/плюс 0.1 с. **[по умолчанию]**

## 8. Горячие клавиши

Работают, когда в фокусе **любое из трёх окон** плеера.
Буквенные клавиши и `,` `.` привязывать к **физическим клавишам**, чтобы они работали
**и в русской раскладке** (S = «ы», B = «и», P = «з», `,` = «б», `.` = «ю» и т. д.).

## 14. Технические заметки и риски

- **Встраивание mpv в WPF:** окно видео содержит `HwndHost` (или `WindowsFormsHost` с Panel),
  его HWND передаётся в mpv опцией `wid`; mpv рисует сам (`vo=gpu`/`gpu-next`).
- **Airspace:** WPF-элементы нельзя рисовать поверх HWND с видео. Поэтому OSD и субтитры — средствами mpv,
  а окно видео не содержит WPF-контролов поверх картинки.
- **Мышь над видео:** дочернее HWND mpv перехватывает сообщения мыши. Клик/двойной клик/колесо/перетаскивание
  нужно получить в нашем коде: варианты — обработка в WndProc хоста, `WM_NCHITTEST → HTTRANSPARENT`
  для дочернего окна, опция `input-cursor=no`. Решить на этапе «Окна» и проверить с пользователем.
- **Перетаскивание безрамочного окна:** `DragMove()` или `WM_NCLBUTTONDOWN` с `HTCAPTION`;
  для окна видео — только после превышения порога движения (иначе это клик-пауза).
- **Пропорции:** размеры видео — из свойств mpv `dwidth`/`dheight` (или `video-params`), учитывать
  анаморфное видео.
- **Потоки:** события libmpv приходят не в UI-потоке — передавать через `Dispatcher`.
- **Завершение:** при закрытии корректно вызывать `mpv_terminate_destroy`, сохранить позицию просмотра и окна.
- **Многомониторность и DPI:** проверить перетаскивание между мониторами с разным масштабом.

## 15. Этапы разработки (каждый — сборка проходит + проверка пользователем)

1. **Скелет:** WPF-проект, P/Invoke-обёртка libmpv, одно окно, открывается файл (аргумент / диалог), играет видео и звук.
   — *Готово, проверено пользователем: видео и звук есть (2026-10-21).*
2. **Окна:** три безрамочных окна в утверждённой палитре; перетаскивание всех трёх, ресайз колёсиком с пропорциями,
   клик = пауза, двойной клик = полный экран, DPI, группа окон.
3. **Панель управления:** кнопки, толстая перемотка, громкость, время — по макету.
4. **Плейлист:** автозагрузка папки, естественная сортировка, автопереход, ручное добавление, перетаскивание, удаление, очистка.
5. **Аудио и субтитры:** меню «Аудио»/«Субтитры», внешние субтитры, кодировки, сдвиги синхронизации.
6. **Горячие клавиши и OSD:** вся таблица раздела 8 в обеих раскладках, подсказки раздела 9.
7. **Запоминание и удобства:** позиции окон, продолжение с места, громкость, скриншоты, поверх всех окон,
   запрет сна, сдвиг окон для нового экземпляра.
8. **Контекстное меню:** по утверждённому составу (раздел 13).
9. **Финал:** «Открыть с помощью», публикация (папка с `Kadr.exe` + `libmpv-2.dll` + `Горячие клавиши.txt`), при желании — установщик (Inno Setup).
