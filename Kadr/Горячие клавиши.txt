KADR — ГОРЯЧИЕ КЛАВИШИ И УПРАВЛЕНИЕ МЫШЬЮ
==========================================

Клавиши работают, когда активно любое из трёх окон плеера
(видео, панель управления, плейлист). Буквенные клавиши работают
в любой раскладке: например, S — это и «S», и «Ы».


ВОСПРОИЗВЕДЕНИЕ
---------------
  Пробел              Пауза / воспроизведение
  ,  (Б)              Назад на 20 секунд
  .  (Ю)              Вперёд на 20 секунд
  Стрелка влево       Назад на 5 секунд
  Стрелка вправо      Вперёд на 5 секунд
  [  (Х)              Медленнее
  ]  (Ъ)              Быстрее
  Backspace           Обычная скорость


ЗВУК
----
  Стрелка вверх       Громче
  Стрелка вниз        Тише
  M  (Ь)              Выключить / включить звук
  A  (Ф)              Следующая аудиодорожка
  Shift+Z             Сдвинуть звук на 0,1 с раньше
  Shift+X             Сдвинуть звук на 0,1 с позже


СУБТИТРЫ
--------
  S  (Ы)              Субтитры вкл / выкл
  Shift+S             Следующая дорожка субтитров
  Z  (Я)              Сдвинуть субтитры на 0,1 с раньше
  X  (Ч)              Сдвинуть субтитры на 0,1 с позже


ПЛЕЙЛИСТ
--------
  B  (И)              Следующий файл
  Page Down           Следующий файл
  V  (М)              Предыдущий файл
  Page Up             Предыдущий файл
  L  (Д)              Показать / скрыть плейлист
  Delete              Убрать выбранный файл из плейлиста
                      (только из списка, с диска файл не удаляется)


ОКНА И ЭКРАН
------------
  F  (А)              Полноэкранный режим вкл / выкл
  Esc                 Выйти из полноэкранного режима
  Tab                 Показать / скрыть панель управления
  Ctrl+A              Поверх всех окон вкл / выкл
  P  (З)              Скриншот кадра (PNG в папку «Изображения»;
                      с субтитрами, если они включены)
  F10                 Закрыть программу


МЫШЬ — ОКНО ВИДЕО
-----------------
  Колёсико            Больше / меньше окно (пропорции сохраняются)
  Левый клик          Пауза / воспроизведение
  Зажать и тянуть     Переместить окно (в том числе на другой монитор)
  Двойной клик        Полноэкранный режим вкл / выкл
  Правый клик         Меню: открыть файл или папку, аудио, субтитры,
                      скорость, размер окна, поверх всех окон и др.

  В полноэкранном режиме левый клик показывает / скрывает
  панель управления (пауза — пробелом).


МЫШЬ — ПАНЕЛЬ И ПЛЕЙЛИСТ
------------------------
  Зажать свободное место и тянуть     Переместить окно
  Клик по полосе перемотки            Перейти в это место
  Клик по полосе громкости            Установить громкость
  Клик по значку громкости            Выключить / включить звук
  Двойной клик по строке плейлиста    Воспроизвести файл
  Правый клик в плейлисте             Меню: добавить файлы, добавить папку
                                      (со всеми подпапками), удалить,
                                      очистить, сортировать по имени


ПЕРЕТАСКИВАНИЕ ФАЙЛОВ
---------------------
  Файл на окно видео      Открыть его; плейлист заменяется
                          всеми видео из его папки
  Файлы или папку         Добавить в конец плейлиста
  в окно плейлиста
